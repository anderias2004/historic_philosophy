# Historic Philosophy — Cloud Render Starter

این بسته یک نقطه شروع فنی برای رندر ابری Remotion روی AWS Lambda است.
این بسته به‌تنهایی یک سرویس آنلاینِ متصل به حساب شما نیست و هنوز AWS یا GitHub را راه‌اندازی نمی‌کند.

## آنچه آماده است
- قالب عمودی 1080×1920، نرخ 30fps و مدت 30 ثانیه
- شناسه Composition: `HistoryReel`
- متن فارسی و واترمارک `@historic_philosophy`
- اسکریپت‌های اولیه استقرار Lambda و سایت Remotion در منطقه `eu-west-1`
- فایل نمونه محیطی؛ بدون هیچ رمز یا کلید واقعی

## مسیر پیشنهادی از گوشی
1. در مرورگر گوشی وارد GitHub شوید و یک حساب بسازید/وارد شوید.
2. یک مخزن خصوصی (Private repository) بسازید.
3. فایل‌های این بسته را در مخزن آپلود کنید.
4. از صفحه مخزن، گزینه **Code → Codespaces → Create codespace on main** را انتخاب کنید. Codespaces یک ترمینال ابری می‌دهد؛ نیازی به نصب Node روی گوشی نیست.
5. در ترمینال Codespaces اجرا کنید:
   ```bash
   npm install
   ```
6. راهنمای رسمی Remotion Lambda را باز کنید و مراحل IAM را در AWS Console انجام دهید:
   https://www.remotion.dev/docs/lambda/setup
7. کلیدهای AWS را فقط در محیط امن Codespaces Secrets یا فایل `.env` محلیِ خارج از Git ذخیره کنید. هرگز کلیدها را در چت، کد، یا مخزن GitHub قرار ندهید.
8. پس از تنظیم دسترسی‌ها:
   ```bash
   npm run validate:aws
   npm run deploy:function
   npm run deploy:site
   npm run quotas
   ```
9. برای رندر نمونه، ابتدا URL سایت ایجادشده را از خروجی `deploy:site` بردارید و فرمان زیر را در ترمینال اجرا کنید:
   ```bash
   npx remotion lambda render YOUR_SERVE_URL HistoryReel --region=eu-west-1 --codec=h264
   ```
10. لینک خروجی MP4 در پایان رندر نمایش داده می‌شود؛ آن را با گوشی باز و ذخیره کنید.

## نکات مهم
- فرمان‌های `deploy:function` و `deploy:site` هزینه و منابع AWS ایجاد می‌کنند. فقط وقتی اجرا کنید که آماده‌اید.
- منطقه انتخاب‌شده در این نمونه `eu-west-1` (ایرلند) است. تابع، سایت و سطل ذخیره‌سازی باید در منطقه سازگار باشند.
- قبل از استفاده واقعی، محدودیت‌های AWS، هزینه‌ها، حریم خصوصی فایل‌ها و حذف خروجی‌های قدیمی را بررسی کنید.
- نسخه‌های `remotion` و بسته‌های `@remotion/*` باید با هم هماهنگ باشند. اگر نسخه را تغییر می‌دهید، همه را یکجا ارتقا دهید و تابع Lambda را دوباره deploy کنید.
- این پروژه هنوز تولید خودکار صدا، اتصال سرویس تبدیل متن به گفتار، ساخت خودکار تصاویر، پنل ورود موضوع، یا تحویل خودکار MP4 به گوشی را ندارد. این‌ها مرحله بعدی توسعه هستند.
- فونت فارسی در رندر ابری باید در پروژه bundle شده و قابل دسترسی باشد؛ در نسخه بعدی باید فونت فارسی مجاز به پروژه اضافه شود و روی رندر واقعی آزمایش گردد.

## مشخصات خروجی هدف
- MP4 / H.264
- 1080×1920
- 30fps
- صدای فارسی در مرحله بعدی
- زیرنویس فارسی و هویت بصری مشکی/طلایی در مرحله بعدی
