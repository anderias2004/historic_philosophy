# Historic Philosophy — Remotion Cloud Starter

این مخزن نقطه شروع فنی ساخت ریلز عمودی برای پیج **@historic_philosophy** است.

## وضعیت فعلی
- Composition با شناسه `HistoryReel` در پوشه `src/` قرار دارد.
- خروجی عمودی 1080×1920، نرخ 30 فریم و مدت پیش‌فرض 70 ثانیه است.
- هویت بصری اولیه مشکی/طلایی و متن فارسی است.
- متن هر صحنه بر اساس زمان شروع و پایان خودش نمایش داده می‌شود و با ورود/خروج هر صحنه محو می‌شود.
- ورودی صدای گویندگی فارسی پشتیبانی می‌شود؛ فایل صدا باید در پوشه `public/` قرار بگیرد.
- انتشار در این مرحله خودکار نیست و باید پس از بازبینی انسانی انجام شود.

## افزودن صدای فارسی
1. فایل گویندگی نهایی را با فرمت MP3 در پوشه `public/` قرار دهید.
2. نام فایل را در props کامپوزیشن با کلید `voiceoverFile` وارد کنید؛ برای نمونه:

```ts
voiceoverFile: "voiceover.mp3"
```

3. صدا از ابتدای ویدیو پخش می‌شود. بهتر است فایل گویندگی دقیقاً برای ساختار 70 ثانیه‌ای تدوین شود.
4. زمان‌های `start` و `end` هر آیتم در آرایه `scenes` را با مکث‌ها و جمله‌های فایل صوتی هماهنگ کنید. متن هر صحنه در همان بازه به‌عنوان زیرنویس/متن روایت روی تصویر می‌آید.

**نکته:** این نسخه فایل صوتی یا صدای هوش مصنوعی تولید نمی‌کند؛ فقط فایل گویندگی آماده را به ویدیو متصل می‌کند. برای تولید صدای واقعی، ابتدا باید فایل صوتی ساخته یا ضبط شود.

## اجرای آزمایشی بدون AWS
در Codespaces، داخل ترمینال:

```bash
git pull origin main
npm install
npm run studio
```

برای ساخت MP4 آزمایشی:

```bash
npm run render:preview
```

فایل خروجی در `out/preview.mp4` ساخته می‌شود.

## راه‌اندازی رندر ابری AWS (هزینه‌زا)
فعلاً هیچ منبع AWS از این مخزن ایجاد نشده است. پیش از راه‌اندازی، حساب AWS، روش پرداخت، بودجه و هشدار هزینه را تنظیم کنید. راهنمای رسمی:
https://www.remotion.dev/docs/lambda/setup

منطقه انتخاب‌شده `eu-west-1` (ایرلند) است. فرمان‌های deploy ممکن است هزینه ایجاد کنند؛ بدون تصمیم و تأیید آگاهانه اجرا نکنید.

## امنیت
- کلیدهای AWS و رمزها را در چت یا مخزن GitHub قرار ندهید.
- از Codespaces Secrets یا متغیرهای محیطی امن استفاده کنید.
- فایل‌های `.env` و خروجی‌های ویدیو نباید وارد Git شوند.
- بهتر است مخزن Private باشد.

## مشخصات هدف
- MP4 / H.264، 1080×1920، 30fps
- روایت و گویندگی فارسی
- هویت بصری مشکی/طلایی و شناسه `@historic_philosophy`
- انتشار با تأیید انسانی (Review) از طریق Metricool
