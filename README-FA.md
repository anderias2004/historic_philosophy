# Historic Philosophy — Remotion Reel Generator

پروژه ساخت ریلز عمودی برای پیج **@historic_philosophy**.

## وضعیت فعلی
- کامپوزیشن `HistoryReel`: خروجی 1080×1920، نرخ 30fps و مدت 70 ثانیه.
- هویت بصری اولیه مشکی/طلایی و متن فارسی.
- متن هر صحنه در بازه زمانی خودش نمایش داده می‌شود.
- اتصال فایل گویندگی MP3 و تولید گویندگی فارسی با Edge TTS پشتیبانی می‌شود.
- صدای پیش‌فرض: `fa-IR-FaridNeural`.
- انتشار خودکار فعال نیست؛ خروجی باید بازبینی و سپس از طریق Metricool منتشر شود.

## تولید صدای فارسی
در ترمینال Codespaces:

```bash
git pull origin main
npm run voice:setup
npm run voice:generate
```

اسکریپت، متن `content/voiceover.txt` را با صدای فارسی مردانه به فایل `public/voiceover.mp3` تبدیل می‌کند. فایل صوتی از ابتدای ویدیو پخش می‌شود.

برای تغییر متن، فایل `content/voiceover.txt` را ویرایش کن. برای استفاده از صدای زنانه، مقدار `VOICE` در `scripts/generate_voice.py` را به `fa-IR-DilaraNeural` تغییر بده و دوباره `npm run voice:generate` را اجرا کن.

**هماهنگی زیرنویس:** متن‌های روی تصویر فعلاً با زمان‌های `start` و `end` در `src/Root.tsx` زمان‌بندی دستی دارند. پس از تولید صدا، زمان‌بندی را با شنیدن خروجی بررسی و در صورت نیاز اصلاح کن؛ هم‌ترازی خودکار کلمه‌به‌کلمه هنوز پیاده‌سازی نشده است.

## پیش‌نمایش و رندر محلی
پس از ساخت فایل صوتی:

```bash
npm run studio
```

برای ساخت MP4:

```bash
npm run render:preview
```

فایل در `out/preview.mp4` قرار می‌گیرد.

## امنیت و انتشار
- کلیدها و رمزها را در GitHub یا چت قرار نده.
- فایل‌های خروجی ویدیو و فایل‌های محیطی را وارد Git نکن.

## افزودن تصاویر سینمایی به صحنه‌ها
1. تصاویر هر ریلز را در پوشه `public/images/` قرار بده.
2. برای هر صحنه در آرایه `scenes`، مسیر تصویر را با کلید `imageFile` مشخص کن. نمونه:

```ts
{
  start: 7,
  end: 16,
  text: "روایت صحنه...",
  imageFile: "images/roman-senate.jpg"
}
```

3. تصویر در همان بازه زمانی نمایش داده می‌شود و حرکت زوم آرام سینمایی دارد. یک لایه تیره نیز برای خوانایی متن روی تصویر قرار می‌گیرد.
4. اگر `imageFile` تعریف نشود، پس‌زمینه گرافیکی مشکی/طلایی فعلی نمایش داده می‌شود.

فرمت‌های پیشنهادی تصویر: JPG یا PNG. نسبت تصویر عمودی 9:16 بهترین نتیجه را می‌دهد؛ تصاویر افقی هم با برش مرکزی نمایش داده می‌شوند.

صدای گویندگی همچنان یک قابلیت اختیاری است؛ برای اجرای نسخه بدون صدا نیازی به فایل MP3 نیست.


## تغییر موضوع و متن ریلز بدون دست‌کاری کد

از این به بعد اطلاعات ریلز از فایل `content/reel.json` خوانده می‌شود. برای ساخت ریلز جدید فقط همین فایل را ویرایش کن:

- `title`: عنوان اصلی ریلز
- `hook`: هوک ابتدای ویدیو
- `handle`: آیدی پیج
- `scenes`: متن و زمان‌بندی صحنه‌ها
- `start` و `end`: زمان شروع و پایان هر صحنه برحسب ثانیه
- `text`: متن نمایشی همان صحنه
- `imageFile`: مسیر اختیاری تصویر در پوشه `public/`، مثل `images/roman-senate.jpg`

نمونه یک صحنه:

```json
{
  "start": 7,
  "end": 16,
  "text": "متن این صحنه را اینجا بنویس",
  "imageFile": "images/roman-senate.jpg"
}
```

نکته‌ها:
1. فایل باید JSON معتبر باشد؛ بین دو فیلد و دو صحنه ویرگول بگذار، اما بعد از آخرین مورد ویرگول نگذار.
2. زمان‌ها را طوری تنظیم کن که صحنه‌ها با هم تداخل نداشته باشند و داخل بازه ۷۰ ثانیه باشند.
3. اگر برای صحنه تصویر نمی‌خواهی، خط `imageFile` را حذف کن.
4. بعد از ذخیره فایل، Studio را بازخوانی کن تا تغییرات نمایش داده شوند.

برای شروع کار در Codespaces:

```bash
git pull origin main
npm run studio
```


## پنل مدیریت ریلز از طریق مرورگر موبایل

برای باز کردن پنل فارسی و ویرایش ریلز بدون دست‌کاری فایل‌های کد:

```bash
git pull origin main
npm run editor
```

در Codespaces:
1. پس از اجرای فرمان، بخش **Ports** را باز کن.
2. پورت **3000** را پیدا کن و گزینه **Open in Browser** را بزن.
3. در پنل، عنوان، هوک و صحنه‌ها را ویرایش کن و روی «ذخیره محتوا در پروژه» بزن.
4. در یک ترمینال دیگر، `npm run studio` را اجرا کن یا Studio باز را Refresh کن تا پیش‌نمایش محتوای جدید را ببینی.

پنل فقط روی محیط Codespaces اجرا می‌شود و فایل `content/reel.json` را در همان workspace ذخیره می‌کند. برای استفاده شخصی، پورت را Public نکن؛ دسترسی آن را روی Private نگه دار.


### ساخت MP4 از داخل پنل

پس از دریافت آخرین تغییرات و اجرای دوباره پنل:

1. `git pull origin main`
2. سرور پنل را متوقف و دوباره با `npm run editor` اجرا کن.
3. در مرورگر پنل، روی «ساخت فایل MP4» بزن.
4. پنل وضعیت رندر را نمایش می‌دهد؛ پس از اتمام، پیوند «مشاهده ویدیو» ظاهر می‌شود.

خروجی در `out/preview.mp4` ذخیره می‌شود. این رندر روی Codespaces اجرا می‌شود و به AWS نیاز ندارد؛ ممکن است بسته به منابع Codespaces چند دقیقه طول بکشد.

## بارگذاری تصویر از گوشی در پنل

در هر صحنه، از قسمت «یا تصویر را از گوشی بارگذاری کن» یک فایل JPG، PNG یا WEBP با حجم کمتر از ۸ مگابایت انتخاب کن. تصویر در `public/images/` ذخیره می‌شود و مسیر آن خودکار برای همان صحنه ثبت می‌شود.

پس از بارگذاری همه تصاویر، روی «ذخیره محتوا در پروژه» و سپس «ساخت فایل MP4» بزن. تصویرهای بارگذاری‌شده در فضای Codespaces ذخیره می‌شوند؛ برای باقی‌ماندن آن‌ها در مخزن Git، باید پوشه `public/images/` را جداگانه commit و push کنی.

## جست‌وجوی خودکار تصویر آرشیوی رایگان

در هر صحنه، عبارت جست‌وجو را به انگلیسی وارد کن؛ برای نمونه `Julius Caesar Roman statue portrait`، سپس روی «جست‌وجو و افزودن تصویر رایگان» بزن. پنل تصویر مناسب را از Wikimedia Commons پیدا می‌کند و در `public/images/` ذخیره می‌کند.

- اطلاعات منبع، پدیدآورنده و مجوز کنار تصویر در فایل `.license.json` ذخیره می‌شود.
- پیش از انتشار، صفحه منبع و شرایط مجوز هر تصویر را بررسی کن و انتساب لازم را در کپشن یا توضیحات درج کن.
- جست‌وجو از عبارت انگلیسی نتیجه بهتری می‌دهد؛ عبارت دقیق و توصیفی بنویس.
- این قابلیت تصاویر آرشیوی را خودکار دریافت می‌کند؛ تولید تصویر هوش مصنوعی هنوز به سرویس جداگانه نیاز دارد و در این نسخه فعال نیست.

برای دریافت قابلیت، در Codespaces اجرا کن:

```bash
git pull origin main
```
سپس سرور پنل را متوقف و دوباره اجرا کن:

```bash
pkill -f 'node scripts/editor-server.mjs' || true
npm run editor
```
