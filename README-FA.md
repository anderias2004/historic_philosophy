# Historic Philosophy — Remotion Reel Generator

پروژه ساخت ریلز عمودی برای پیج **@historic_philosophy**.

## وضعیت فعلی
- کامپوزیشن `HistoryReel`: خروجی 1080×1920، نرخ 30fps و مدت 70 ثانیه.
- هویت بصری اولیه مشکی/طلایی و متن فارسی.
- متن هر صحنه در بازه زمانی خودش نمایش داده می‌شود.
- اتصال فایل گویندگی MP3 و تولید گویندگی فارسی با Edge TTS پشتیبانی می‌شود.
- صدای پیش‌فرض: `fa-IR-FaridNeural`.
- انتشار خودکار فعال نیست؛ خروجی باید بازبینی و سپس از طریق Metricool منتشر شود.

## تولید صدای فارسی
در ترمینال Codespaces:

```bash
git pull origin main
npm run voice:setup
npm run voice:generate
```

اسکریپت، متن `content/voiceover.txt` را با صدای فارسی مردانه به فایل `public/voiceover.mp3` تبدیل می‌کند. فایل صوتی از ابتدای ویدیو پخش می‌شود.

برای تغییر متن، فایل `content/voiceover.txt` را ویرایش کن. برای استفاده از صدای زنانه، مقدار `VOICE` در `scripts/generate_voice.py` را به `fa-IR-DilaraNeural` تغییر بده و دوباره `npm run voice:generate` را اجرا کن.

**هماهنگی زیرنویس:** متن‌های روی تصویر فعلاً با زمان‌های `start` و `end` در `src/Root.tsx` زمان‌بندی دستی دارند. پس از تولید صدا، زمان‌بندی را با شنیدن خروجی بررسی و در صورت نیاز اصلاح کن؛ هم‌ترازی خودکار کلمه‌به‌کلمه هنوز پیاده‌سازی نشده است.

## پیش‌نمایش و رندر محلی
پس از ساخت فایل صوتی:

```bash
npm run studio
```

برای ساخت MP4:

```bash
npm run render:preview
```

فایل در `out/preview.mp4` قرار می‌گیرد.

## AWS
هیچ منبع AWS ایجاد نشده است. راه‌اندازی Remotion Lambda ممکن است هزینه داشته باشد؛ تا پیش از تصمیم آگاهانه، فرمان‌های deploy را اجرا نکن. راهنمای رسمی:
