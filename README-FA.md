# Historic Philosophy — Remotion Cloud Starter

این مخزن نقطه شروع فنی ساخت ریلز عمودی برای پیج **@historic_philosophy** است.

## وضعیت فعلی
- ساختار اصلی Remotion در پوشه `src/` قرار دارد.
- Composition با شناسه `HistoryReel` ساخته شده است.
- ابعاد خروجی: 1080×1920، نرخ 30 فریم و مدت پیش‌فرض 30 ثانیه.
- قالب اولیه گرافیکی مشکی/طلایی و متن فارسی دارد.
- فرمان پیش‌نمایش محلی و فرمان رندر ابری در `package.json` تنظیم شده‌اند.
- فایل‌های کلید و رمز در Git نادیده گرفته می‌شوند.

**توجه:** این نسخه فقط قالب اولیه ویدیویی است؛ هنوز تولید خودکار سناریو، صدای فارسی، تصاویر اختصاصی، زیرنویس زمان‌بندی‌شده، پنل سفارش ریلز، ارسال خودکار فایل و انتشار در Metricool پیاده‌سازی نشده‌اند.

## اجرای آزمایشی بدون AWS
در GitHub از مسیر **Code → Codespaces → Create codespace on main** یک محیط ابری باز کنید. در ترمینال:

```bash
npm install
npm run studio
```

برای ساخت یک MP4 آزمایشی در همان محیط:

```bash
npm run render:preview
```

فایل خروجی در مسیر `out/preview.mp4` قرار می‌گیرد.

## راه‌اندازی رندر ابری AWS (هزینه‌زا)
فعلاً هیچ منبع AWS از این مخزن ایجاد نشده است. قبل از ادامه، حساب AWS، روش پرداخت، بودجه و هشدار هزینه را تنظیم کنید. سپس راهنمای رسمی را دنبال کنید:

https://www.remotion.dev/docs/lambda/setup

منطقه انتخاب‌شده در این پروژه `eu-west-1` (ایرلند) است. پس از تنظیم مجوزهای AWS در محیط امن Codespaces:

```bash
npm run validate:aws
npm run deploy:function
npm run deploy:site
npm run quotas
```

پس از اجرای موفق `deploy:site`، آدرس سایت Remotion را در متغیر محیطی قرار دهید:

```bash
export REMOTION_SERVE_URL="آدرس-سایت-ایجادشده"
npm run render:caesar
```

فرمان رندر ابری به آدرس سایت و تابع Lambda نیاز دارد و ممکن است هزینه AWS ایجاد کند. تا زمانی که آگاهانه تصمیم به راه‌اندازی AWS نگرفته‌اید، فرمان‌های deploy را اجرا نکنید.

## امنیت
- هیچ‌وقت AWS Access Key، Secret Key یا رمزها را در چت، فایل کد یا مخزن GitHub قرار ندهید.
- از Codespaces Secrets یا متغیرهای محیطی امن استفاده کنید.
- فایل `.env` و فایل‌های خروجی ویدیویی در `.gitignore` قرار دارند.
- بهتر است مخزن حاوی کدهای پروژه را Private نگه دارید.
